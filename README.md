# Student Performance Factors Analysis

## Project Description
This project focuses on analyzing student academic performance using Python. It explores various factors that influence students' exam scores, such as study hours, attendance, sleep hours, parental involvement, teacher quality, and other academic and lifestyle factors.

## Objectives
- Analyze the factors affecting student academic performance.
- Understand the relationship between study hours and exam scores.
- Analyze the impact of attendance on academic performance.
- Explore the influence of parental involvement on student performance.
- Identify patterns and trends using data visualization.

## Dataset
- **Dataset Name:** Student Performance Factors
- **Source:** Kaggle
- **Records:** 6,607
- **Features:** 20
- **File Format:** CSV

Dataset Link: https://www.kaggle.com/datasets/lainguyn123/student-performance-factors
